# 足球赛事比分预测器 · 多赛事扩展设计（P0 调研 + 信息架构）

> 2026-07-08 起草（世界杯 R16 进行中）。目标：把「世界杯比分预测器」升级为「足球赛事比分预测器」，
> 覆盖全部 S 级赛事；本文档回答两个问题——**做哪些赛事、按什么顺序**，以及**页面怎么分级分层**。
> 铁律沿用主项目：引擎改动必须回测证明；竞彩红线（无买入指令、无跨场聚合率）对所有赛事一体生效。

## 一、S 级赛事清单与分级（产品视角）

| 层级 | 赛事 | 类型 | 周期 | 数据可行性（已实测） |
|---|---|---|---|---|
| S · 国家队 | 世界杯 | 杯赛(小组+括号) | 4 年 | ✅ 已上线（本项目） |
| S · 国家队 | 欧洲杯 | 杯赛 | 4 年（2028 英爱） | ✅ martj42 正赛 388 场 + 预选赛 2824 场 |
| S · 国家队 | 美洲杯 | 杯赛 | 4 年（2028） | ✅ martj42 869 场 |
| S− · 国家队 | 非洲杯 | 杯赛 | 2 年（2027 摩洛哥暂定） | ✅ martj42 845+2327 场 |
| S− · 国家队 | 亚洲杯 | 杯赛 | 4 年（2027 沙特） | ✅ martj42 421+829 场 |
| S− · 国家队 | 欧国联 | 联赛+决赛圈 | 2 年（2026-27 赛季秋启） | ✅ martj42 658 场 |
| S · 俱乐部 | 欧冠 | 瑞士轮+括号 | 年度（8 月资格赛） | ⚠️ 需新数据源（见 §3） |
| S · 俱乐部 | 英超/西甲/意甲/德甲/法甲 | 双循环联赛 | 年度（8 月开赛） | ✅ football-data.co.uk 免费 CSV（含闭盘赔率！） |
| S− · 俱乐部 | 世俱杯 | 杯赛 | 4 年（2029） | ⚠️ 跨联赛评级难题，远期 |

**关键事实（本次已验证）**：
1. **国家队 S 级赛事零数据成本**——martj42 `results.csv` 全覆盖，且现有 DC 引擎本就在全量国际赛上训练
   （257 队），`predict.py "Germany" "Italy"` 今天就能出任意国家队对阵的预测。缺的只是「赛事外壳」
   （赛程/括号/模拟/验证账本）。
2. **ESPN 实时层全赛事可参数化**——scoreboard/summary API 按 league code 切换即可：
   `uefa.euro`(id 781) / `conmebol.america` / `caf.nations` / `afc.asian.cup` / `uefa.nations` /
   `uefa.champions` / `eng.1 esp.1 ita.1 ger.1 fra.1` / `fifa.cwc`（全部实测有响应）。
   现有 `live.py`/`espn_odds.py` 只需把写死的 `fifa.world` 抽成参数。
3. **俱乐部是另一个模型宇宙**——martj42 只有国际赛。五大联赛用 football-data.co.uk（已实测：
   `mmz4281/2425/E0.csv` 英超 24-25 全 380 场，Date/队名/FTHG/FTAG + **B365 开盘(B365H)与闭盘(B365CH)
   赔率原生齐全**——CLV 层条件比世界杯还好，无需快照调度攒开盘）；欧冠免费历史数据源较散
   （fbref 反爬、openfootball 不全），P2 再解。**国家队评级与俱乐部评级不可混训**（无共同对手锚，
   强度不可比）。

## 二、页面信息架构：三层分级（本次核心结论）

```
L0 赛事层（新增）            L1 赛事内功能层（复用现有 8 tab）      L2 单场层（不动）
┌──────────────────┐      ┌──────────────────────────────┐      ┌────────────┐
│ 顶栏赛事切换器      │  →   │ 看板 / 对阵分析 / [晋级树|积分榜] │  →   │ 比分矩阵弹窗 │
│ (进行中置顶+分组)   │      │ / 夺冠概率 / 市场 / 解读 / 复盘  │      │ 深度报告     │
└──────────────────┘      └──────────────────────────────┘      └────────────┘
```

### L0 赛事层——切换器 + 状态驱动排序
- 形态：顶栏（现标题下方）一行**赛事 chip**，或收进下拉。排序规则（自动，非手排）：
  **进行中 > 30 天内开赛 > 常青联赛（赛季中）> 归档**。世界杯期间世界杯永远第一。
- 每个 chip 带状态徽标：`● LIVE`（today 有比赛）/ `倒计时 N 天` / `赛季 25-26` / `已归档`。
- URL 口径：`#<event>/<tab>`（如 `#euro2028/bracket`），现有 `#bracket` 深链 301 到
  `#wc2026/bracket`——**旧链接零破坏**。

### L1 功能层——赛制驱动 tab 集（分层的核心逻辑）
tab 不是每赛事全量复制，而是按**赛制类型**装配（配置驱动，见 §4 registry）：

| tab | 杯赛(小组+括号) | 联赛(双循环) | 瑞士轮+括号(新欧冠) |
|---|---|---|---|
| 赛事看板 | ✅ | ✅ | ✅ |
| 对阵分析(经理人) | ✅ | ✅ | ✅ |
| 晋级树 | ✅ | ❌ → **积分榜/夺冠赛道** | ✅（瑞士轮阶段=大积分榜） |
| 夺冠概率(MC) | ✅ | ✅（模拟余下轮次） | ✅ |
| 市场对标/机制解读 | 有盘口才开 | ✅（football-data 自带闭盘） | 有盘口才开 |
| 竞彩复盘 | ✅（红线一体） | ✅ | ✅ |
| 玄学占卜 | ✅ | 可关 | 可关 |

- **数据可用性驱动功能开关**：无盘口源→市场层整 tab 隐藏（不是空态）；无官方赛程→夺冠概率显示
  「赛程未公布，仅实力榜」降级。
- **验证账本按赛事隔离**：`predictions_<event>.json`——绝不混池算命中率（不同赛事基础难度不同，
  混池=自欺，同竞彩红线气质）。

### L2 单场层——零改动
比分矩阵弹窗、足球经理人报告、读盘卡、解读卡全部与赛事无关（吃 model+两队名），天然复用。

## 三、模型宇宙（引擎层分级）

| 宇宙 | 训练数据 | 模型实例 | 覆盖赛事 |
|---|---|---|---|
| 国家队 | martj42 全量国际赛（现状） | 现有 `model.pkl`（一个） | 世界杯/欧洲杯/美洲杯/非洲杯/亚洲杯/欧国联 |
| 俱乐部·五大联赛 | football-data.co.uk 各联赛 CSV | 每联赛一个 `model_<lg>.pkl`（跨联赛无共同锚，先不混） | 英超/西甲/意甲/德甲/法甲 |
| 俱乐部·跨联赛 | （欧冠需要）多联赛拼接+洲际杯赛锚 | P2 再研究（联赛间强度校准是学术级难题） | 欧冠/世俱杯 |

- half_life=730 是**国家队口径**的回测最优；俱乐部**已正式复扫裁决（2026-07-08，`bt_club_hl.py`，
  5 联赛 × 3 时序 cutoff × 8 档网格）**：
  - **P2 采纳：统一 half_life=365**（跨联赛平均 RPS 0.2018 最优；240 并列）。曲线在 180–545 是
    平底盆地，每联赛距自身最优 ≤0.0016——不为噪声级差异开 per-league 超参。
  - 各联赛最优：E0=180、SP1=240、I1=545、D1=365、F1=545；730（国家队最优）在所有联赛都不是最优。
    首扫"120-240"结论系英超单联赛+双 cutoff 窄样本，已被正式扫修正——留作"首扫只定方向"纪律实例。
  - **E1（英冠）并入 = 分场景取舍**：**单场预测不并入**（无跳场 cutoff（25-01，同 n=192 严格可比）
    RPS +0.0036 变差，过不了"不变差 ±0.001"闸门）——英超用 E0 单独模型，升班马对阵前端标
    "顶级联赛数据不足"；**赛季模拟必须并入**（`clubsim.simulate_retro(feeder="E1")`：跳过升班马
    整队 38 场会扭曲全表，覆盖优先于微小准度差）；后续可研究 E1 降权并入（w<1）。
- **联赛赛季模拟器已建成并回溯验证（`clubsim.py`，2026-07-08）**：as_of 前=事实、后=DC 抽样，
  N 次终局 → 冠军/前四/降级概率 + 期望积分名次（积分>净胜>进球排序，西甲相互战绩 P3 插拔）。
  **24-25 英超回溯：半程视角利物浦 86.5% 夺冠（史实夺冠 84 分）、降级概率前三=真实降级三队
  （南安普顿 99.4%）**；赛季前视角曼城 72.7% 系诚实先验（卫冕四连冠背景）。注意 DC 点估无参数
  不确定性、夺冠概率偏自信——贝叶斯 CI 层（champ_ci 思路）可平移，P2 可选。实况模式的未来赛程
  接 football-data fixtures.csv（P2 接线）。
- 东道主/中立场逻辑：联赛全部主客场（home_adv 直接生效）；杯赛沿用 venues 映射思路。

## 四、落地形态：event registry（配置驱动，不写 if 森林）

```python
# events.py（新）——每赛事一条注册，L0/L1 全由此驱动
EVENTS = {
  "wc2026":   dict(name="世界杯 2026", kind="cup",    universe="intl",
                   espn="fifa.world",  data_filter='tournament == "FIFA World Cup"',
                   schedule="schedule.py 现状", bracket="wc2026.py 现状",
                   window=("2026-06-11","2026-07-19")),
  "nl2026":   dict(name="欧国联 26-27", kind="league_cup", universe="intl",
                   espn="uefa.nations", data_filter='tournament == "UEFA Nations League"',
                   window=("2026-09-01","2027-06-30")),   # P1 第一个新赛事（秋季开打）
  "epl2526":  dict(name="英超 25-26",  kind="league", universe="club_eng",
                   espn="eng.1", odds_src="football-data",
                   window=("2026-08-08","2027-05-23")),   # P2 第一个俱乐部赛事
  # euro2028 / copa2028 / afcon2027 / asian2027 / ucl … 同构追加
}
```

现有模块的参数化改造点（均已定位）：
- `live.py` / `espn_odds.py`：league code 参数化（现写死 fifa.world）。
- `simulate.py`：`TournamentSimulator` 拆「小组+括号」通用器 + 每赛事 format 插件
  （联赛=模拟余下轮次积分；瑞士轮=配对约束模拟）。
- `verify.py` / `jc_review.py`：账本路径按 event key 隔离。
- `app.py`：全 API 加 `?event=` 参数（默认 wc2026，向后兼容）。
- `teams_zh.py`：俱乐部队名中文映射需新表（国家队表复用）。

## 六、风险与红线（先写死，防走样）
1. **竞彩红线全赛事一体**：任何新赛事的市场/复盘层沿用 `_BANNED`/schema 断壁/红线铁测，联赛玩法更多
   （角球/半场盘）**一律不做**——定位仍是「认清打不赢市场」，不是找 edge。
2. **模型宇宙隔离是硬约束**：国家队与俱乐部评级不混训、验证账本不混池、跨宇宙对阵（如"皇马 vs 阿根廷"）
   直接不支持（无统计意义）。
3. **不为扩展重写引擎**：DC 核心零改动，改的只是数据装载与赛事外壳；每个宇宙的超参独立回测。
4. **世界杯运行期冻结**：7-19 决赛前只做不碰现有功能的增量（本文档、registry 草稿），大改等归档。
