# 数据源选型结论

更新：2026-07-19。本文档整合自 CLAUDE.md 2026-07-08 至 07-16 各期已实测记录与 `docs/MULTI_EVENT_PLAN.md` 的调研结论；所有「已实测」条目均有实际请求/装载运行记录，非推测。

## 一、选定方案（已裁决，勿重新选型）

| 宇宙 | 主源 | 备源/辅助 | 状态 |
|---|---|---|---|
| 国家队（世界杯/欧洲杯/美洲杯/非洲杯/亚洲杯/欧国联） | martj42 international results（全国际赛历史比分） | ESPN API（实时比分、赔率快照） | 已实测，生产使用中 |
| 俱乐部（五大联赛） | football-data.co.uk 按季 CSV | ESPN API（league code 参数化，eng.1/esp.1/ita.1/ger.1/fra.1 均实测有响应） | 已实测，装载层 `clubdata.py` 生产可用 |

## 二、football-data.co.uk（俱乐部主源）实测明细

- 免费额度：完全免费，无 API key，按季静态 CSV 下载。
- 更新频率：赛季进行中每轮后更新当季 CSV（装载层以 CSV mtime 触发模型自动重训）。
- 字段覆盖：比分、半场比分、射门/射正/角球/牌，以及 **B365 开盘+闭盘 1X2 赔率原生齐全（闭盘覆盖实测 100%）**——CLV/市场对标条件优于世界杯侧。
- 已缓存：`data/club/` 下 E0/SP1/I1/D1/F1 各约 7 季（E0 计 2660 场），另有 E1/SP2/I2/D2/F2 五个次级联赛仅作赛季模拟 feeder（升班马历史，`clubdata.FEEDER` 映射）。
- 已知口径坑：25-26 新赛季（8 月初开赛）需 `clubdata._CUR_END` +1 后 `--refresh`。

## 三、martj42（国家队主源）实测明细

- 免费额度：GitHub 公开仓库，免费。
- 覆盖：全部国际 A 级赛事历史比分；S 级赛事正赛场次实测计数：欧洲杯 388、美洲杯 869、非洲杯 845、亚洲杯 421、欧国联 658——现引擎（257 队全国际赛训练）今天即可预测任意国家队对阵。
- 口径坑：数据集 `"FIFA World Cup qualification"` 不等于正赛，过滤正赛必须精确 `== "FIFA World Cup"`；`results.csv` 记含加时全场比分，与竞彩 90 分钟口径不同（jc_review 因此手填 90 分钟比分，不复用该文件）。

## 四、任务书候选源的落选原因

- **football-data.org（API 版）**：免费层有请求频率与赛季深度限制，且不含 B365 开/闭盘赔率列——市场对标层（本项目已建成 `bt_club_market.py`）依赖开+闭盘，故不如 football-data.co.uk CSV。未接入。
- **API-Football**：免费层 100 请求/天，拉 5 联赛 3 季历史远超额度；付费才实用。未接入。
- **openfootball**：社区维护、更新滞后且无赔率字段。未接入。
- **understat xG（任务书可选增强）**：俱乐部侧可抓但反爬，需真实浏览器 CDP；国家队侧无免费源，已裁决为死胡同。暂缓，不阻塞主线。
- **伤停信息**：无稳定免费结构化源。未接入，界面不展示伤停。

## 五、统一数据模型说明（对任务书阶段 1.3 的实现口径）

任务书要求 league/season/match/team 四表。本项目的等价实现：

- `events.py` 注册表 = league/season 维（wc2026/nl2026/epl2526/laliga2526/seriea2526/bundes2526/ligue12526，含赛程窗口、ESPN code、账本文件、tab 配置；账本按赛事隔离是 registry 层不变量）。
- `clubdata.load(code)` 归一帧 = match 维（统一引擎 schema，与国家队数据同构，neutral=False）。
- `teams_zh` 双命名空间 = team 维（国家队 CN 与俱乐部 CLUB 分离，测试断言零交集、俱乐部全覆盖）。
- 世界杯数据不迁移进俱乐部表结构：国家队与俱乐部是两个模型宇宙（half_life 730 vs 365，均经正式裁决），共用引擎但数据分池——这是经回测裁决的架构，非「两套并行结构」的技术债。

## 六、更新机制现状与缺口（诚实标注）

- 已有：CSV mtime 触发的模型自动重训；`clubpredict.py --refresh` 手动强拉进行中赛季；界面「数据更新于 X 时间」时间戳属 P1/P2 接线交付件。
- 缺口（未做，待 P2）：俱乐部数据每日定时抓取脚本（当前为按需拉取；赛季未开，无每日更新需求）。此项在 25-26 赛季开赛前随 P2 落地，落地前一律标注「未验证」。
