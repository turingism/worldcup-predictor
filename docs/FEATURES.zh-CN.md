# 足球赛事预测器：完整产品说明

<p align="right"><a href="./FEATURES.md">English</a> · <strong>简体中文</strong></p>

本文对应当前 UI v2，覆盖跨赛事首页、世界杯、欧国联和欧洲五大联赛。产品围绕三层结构组织：赛事总览、赛事内功能、单场分析。

## 1. 赛事控制台

打开网页默认进入 `#home`。首页不承担单一赛事的详情展示，而是汇总整个系统的当前状态。

<p align="center">
  <img src="./evidence/ui-v2-home-desktop-1440x900.png" alt="赛事控制台桌面端" width="900">
</p>

首页依次展示：

1. **下一赛事**：显示距离最近赛事或赛季开赛的时间。
2. **数据状态**：国家队数据库、五大联赛历史库、欧战账本、赛程源和开球时间核验分别展示。
3. **近期比赛流**：汇总未来 14 天赛事，逐场显示北京时间、对阵和胜平负概率。
4. **赛事目录**：国家队与俱乐部分组，每张卡显示赛季状态、数据截至时间与 readiness。
5. **验证账本**：每个赛事独立成卡；尚无记录的赛事合并为空状态说明，但不合并统计。
6. **数据覆盖**：展示当前数据库的球队、比赛与赛季覆盖事实。

首页概率遵循固定优先级：

- 已冻结比赛使用赛前冻结值，并显示 `frozen_at`。
- 尚未冻结但看板已经能够计算时，显示“当前模型估算（未冻结）”。
- 模型或数据尚不支持时，显示明确空态，不补造数字。

## 2. 全局导航与响应式结构

桌面端采用 220px 赛事侧栏，内容区保持流式宽度。侧栏按国家队和俱乐部分组，并显示开赛倒计时、进行中或归档状态。

在宽度不超过 900px 时：

- 赛事侧栏切换为横向滚动导航。
- 当前赛事自动滚入可见区域。
- 赛事总览入口保持在导航起始位置。
- 功能 Tab 保持单行并独立横向滚动。

在宽度不超过 620px 时：

- 卡片、表单和状态块改为单列。
- 对阵输入框上下排列，交换按钮旋转为纵向关系。
- 次级按钮和导航目标保持至少 44px 高度。
- 宽表格进入 `.hscroll`，页面根节点保持无横向溢出。

## 3. 赛事看板

赛事看板是每个赛事的默认详情页。

### 国家队赛事

世界杯看板包含：

- 已结束、进行中和即将开赛的比赛状态。
- 开球前冻结的概率与赛后真实结果。
- 胜平负结果、比分核对、RPS 和置信度分桶。
- 按比赛查看比分概率矩阵和深度分析入口。
- ESPN 实时赛果读取与本地数据刷新。

### 俱乐部联赛

五大联赛看板包含：

- 下一轮或未来 14 天赛程。
- 胜 / 平 / 负概率、期望进球、概率条和可用的 B365 字段。
- 最近完赛轮与当前积分榜。
- 赛季、数据截至时间、赛程来源和模型基础说明。
- 有冻结值时优先展示冻结值；否则明确显示当前估算口径。

升班马没有足够顶级联赛样本时，系统按联赛调用对应次级联赛合训模型。页面逐场标明“升班马合训估算”和 feeder 权重，不与纯顶级联赛模型混作同一口径。

## 4. 对阵分析

对阵分析把单场模型输出组织为一份完整报告。

输入：

- 主队 / 第一支球队。
- 客队 / 第二支球队。
- 国家队场景可选择中立场；联赛固定使用真实主客场。
- 深链支持通过 `?h=&a=` 直接带入指定对阵。

输出：

- 胜平负概率、最可能比分与期望进球。
- 6×6 或完整比分概率矩阵。
- 近期状态、主客场拆分、历史交锋和攻防强度。
- 大小球、双方进球、总进球、让球分布等派生概率。
- 赛程、球场、开球时间与可用性数据。

国家队页面可在赛前约一小时读取 ESPN 确认首发，并展示纯模型与首发确认后的概率变化。该层是按场次启用的上下文输入，不改写历史训练集。

## 5. 世界杯晋级树

世界杯采用官方 2026 赛制：12 个小组、32 强淘汰赛和最佳第三名分配。

<p align="center">
  <img src="./evidence/ui-v2-wc-bracket-desktop-1440x900.png" alt="世界杯官方赛制晋级树" width="900">
</p>

晋级树支持：

- 实际赛果锁定与未赛场次投影。
- 北京时间 / 当地时间切换。
- 小组赛积分、出线状态与淘汰赛路径。
- 修改假设比分后重算后续路径。
- 晋级树与夺冠概率交叉跳转。

晋级树展示的是一条最可能路径；夺冠页展示的是多次模拟形成的概率分布，两者含义不同。

## 6. 赛季推演与夺冠页

俱乐部联赛不使用杯赛树，而是模拟剩余赛程。

赛季推演页包含：

- 夺冠、前四和降级概率。
- 期望积分与期望排名。
- 不同 `as_of` 时间点的概率轨迹。
- 赛季终局或进行中状态。

夺冠页进一步展示：

- 争冠概率随赛季推进的变化。
- 概率跳变较大的关键时间窗。
- 同一时间窗内的真实比赛结果。
- 联赛内实力排名和不确定性说明。

世界杯夺冠页采用蒙特卡洛赛事模拟，并可读取贝叶斯伪后验区间产物。区间代表参数不确定性与模拟噪声的组合，不应与单一路径投影混淆。

## 7. 市场对标与机制解释

市场对标页把模型概率与可用的开盘、闭盘或让球价格放在同一张评估表中，重点展示：

- 模型、开盘和闭盘的 RPS。
- Shin 去水后的隐含概率。
- 开盘到闭盘的线移动。
- CLV 样本量、均值、t 值和覆盖闭盘的比例。
- 模型让球点估与市场线对实际净胜球的误差。

机制解释页针对单场比赛拆解：

- 1X2 与让球价格结构。
- overround 与去水概率。
- 模型和市场之间的逐结果差异。
- 当前样本与历史基准能支持的解释范围。

这些页面是预测质量评估和价格结构说明层，不参与模型训练，也不写入赛事验证账本。

## 8. 单场复盘

复盘页允许录入一场比赛的让球线、赛前判断和赛后 90 分钟比分，形成单场三方对账：用户记录、模型冻结值、市场线。

- 赛前字段与模型概率一起冻结。
- 赛后只写入真实比分与结算结果。
- 加时和点球不进入 90 分钟结算字段。
- 世界杯与各联赛使用独立存储文件。

该页面是赛事内的独立旁路，不写主验证账本，不触发模型训练。

## 9. 数据与模型

### 国家队宇宙

- 数据：martj42 国际比赛历史、世界杯赛程、ESPN 即时状态。
- 模型：Dixon-Coles 双泊松，球队进攻 / 防守、真实主场优势、时间衰减、低比分相关修正。
- 生产半衰期：730 天。
- 赛事：世界杯、欧国联以及任意国家队单场。

### 俱乐部宇宙

- 数据：football-data.co.uk 历史赛果与赔率字段；ESPN 完整赛程。
- 模型：每个顶级联赛独立拟合。
- 生产半衰期：365 天。
- 升班马：按联赛使用 feeder 数据合训，并在响应和页面上标记基础。

### 验证纪律

- 训练和预测按时间顺序切分。
- 模型或参数改动必须比较 RPS、LogLoss 和命中表现。
- 未通过采纳闸门的实验保留为负结论，不进入生产。
- 验证账本按赛事和赛季隔离。

## 10. 静态版与本地版

本地 Flask 版本运行完整功能。GitHub Pages 版本由 `export_static.py` 在构建期预渲染只读 API。

静态版支持：

- 首页和赛事导航。
- 已导出的看板、比赛概率、赛季推演和验证数据。
- 深链与响应式页面。

本地版额外支持：

- 实时数据刷新。
- 假设比分与重算。
- 本地复盘录入。
- 数据更新和缓存重建。

## 11. 可访问性与浏览器验收

UI v2 的验证不依赖“截图看起来正常”，而是读取浏览器真实盒模型。

- 390 / 430 / 768 / 1440 四档视口检查页面根宽、Tab 行数、文本裁切和滚动容器。
- 17 条主要路由在 390 与 1440 两个视口逐页检查，共 34 条结果。
- 动态 `onclick` 目标补充键盘角色与焦点。
- 输入框、选择器和文本域具备可读标签。
- 文本颜色按 WCAG AA 目标检查。
- `prefers-reduced-motion` 下关闭非必要动画。
