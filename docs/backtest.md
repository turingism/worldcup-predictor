# 俱乐部联赛模型回测报告

更新：2026-07-19。整合自 `bt_club_hl.py`（半衰期裁决扫描）与 `bt_club_market.py`（市场对标基线）两个回测脚本的已跑通结果（记录于 CLAUDE.md 2026-07-08 / 07-16 接手档案）。回测纪律与国家队主线一致：时序 as-of 切分训练、评测后置窗口、无泄漏。

## 一、模型形态

- 引擎：Dixon-Coles 双泊松（与世界杯同一引擎 `model.py`，对俱乐部数据零改动可用，neutral=False 主场口径）。
- 每联赛独立模型（E0/SP1/I1/D1/F1 各一），进攻/防守强度与主场优势系数按联赛独立拟合——满足任务书「联赛差异化参数」要求。
- 动态更新：指数衰减加权（近期比赛权重高），衰减系数经回测裁决（见下）；数据更新后模型自动重训。

## 二、半衰期（衰减系数）正式裁决 — bt_club_hl.py

方法：5 联赛 × 3 时序 cutoff × 8 档半衰期网格，共 120 次拟合，指标 RPS。

- **采纳 half_life=365 天全联赛统一**：跨联赛平均 RPS 0.2018 最优（240 并列）；180–545 为平底盆地，每联赛距自身最优差 ≤0.0016，不为噪声开 per-league 超参。
- 各联赛单独最优：E0=180 / SP1=240 / I1=545 / D1=365 / F1=545。
- **730（国家队最优值）在所有联赛均非最优**——国家队超参不可照搬俱乐部（换血快、赛程密度高）。
- 方法论教训留档:首扫（单联赛双 cutoff）曾得出 120-240 结论,复扫修正——首扫只定方向。
- 英冠 E1 并入单场模型：否决（严格可比口径下 RPS +0.0036 变差）；E1 仅作赛季模拟 feeder（跳过升班马整队 38 场会扭曲全表，覆盖收益大于微小准度损失，分场景裁决）。

## 三、校准度与市场基线对比 — bt_club_market.py

任务书要求「回测未达到优于赔率隐含概率基线要说明原因，禁止美化」。如实结论：

- 样本：约 2700 场（2023-08 / 2024-08 / 2025-01 三窗，每窗 hl=365 as-of 训练、后 180 天评测），三方对比（模型 / B365 开盘 / B365 闭盘，Shin 方法去水）。
- **闭盘市场在全部 5 联赛胜模型**：RPS gap E0 +0.0122 / SP1 +0.0100 / I1 +0.0079 / D1 +0.0110 / F1 +0.0090，跨联赛 +0.0100。命中率闭盘 55.2% vs 模型 51.9%。
- 原因说明（非美化）：闭盘价格聚合了阵容/伤停/临场信息流，公开历史比分模型结构上不可能稳定胜出；国家队侧同款结论（gap +0.0118）。这正是本项目「市场诚实层」的定位依据——预测输出用于研究与信息展示，明示模型与市场的差距，禁止衍生任何投注建议。
- 附带发现：闭盘比开盘更锐利（跨联赛 −0.0007）；例外意甲开盘微好于闭盘（0.1815 vs 0.1823），如实记录。
- 交叉验证：本脚本模型跨联赛 RPS 0.2014 ≈ bt_club_hl 裁决口径 0.2018，两脚本口径互证。

## 四、赛季模拟器回溯验证 — clubsim.simulate_retro

24-25 赛季五大联赛，半程视角（as_of=2025-01-01），每联赛 3000-5000 次模拟，feeder 并入：

- 英超：利物浦 86.5% 夺冠（史实 84 分夺冠）；降级概率前三 = 真实降级三队（南安普顿 99.4% / 伊普斯维奇 70.9% / 莱斯特 61.6%）。
- 德甲：拜仁 89.3% 命中；降级 2/2 全中。法甲：巴黎 98.2% 命中，降级 2/3。
- 未命中（如实记录）：西甲给皇马 56.3% 而实际巴萨（16.8%）、意甲给国米 80.7% 而实际那不勒斯（6.7%）——两者恰为下半程翻盘冠军；暴露已归档短板「DC 点估无参数不确定性，夺冠概率偏自信」。若修，方向为贝叶斯参数不确定性平移（champ_ci 已有先例），不动排序与引擎。
- 25-26 季前首跑（升班马经 feeder 并入、映射已补齐）：英超曼城 42.7%/阿森纳 27.4%/利物浦 27.2%；西甲巴萨 48.0%；意甲国米 62.8%；德甲拜仁 80.1%;法甲巴黎 83.2%。桑德兰降级 99.2% 判为点估偏自信的已知短板放大，非机制 bug。

## 五、输出格式合规性（对任务书阶段 2.4）

`clubpredict.py` 实测输出：胜平负三向概率（归一化，测试断言）、Top 7 最可能比分及概率、xG、大小球 2.5、BTTS——覆盖并超出任务书「最可能 3 比分 + 胜平负分布」要求。结算口径统一 90 分钟（含补时，不含加时点球）。
